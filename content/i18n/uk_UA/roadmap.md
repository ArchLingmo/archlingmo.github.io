## Дорожня карта

Що ми ще збудуємо. Те, що вже готово, описано в розділі [Можливості](#recursos).
Дати орієнтовні й можуть змінитися. Пропозиції та пріоритети обговорюємо в нашому
Discord, а кожен пункт стає відкритим pull request на GitHub.

Пріоритети визначає те, що найчастіше згадують на форумах і в оглядах інших дистрибутивів:
страх, що оновлення зламає систему, драйвери, встановлення програм без термінала та
догляд за комп’ютером без технічних знань.

### 28/09 – 08/11 · Програми без клопоту (і безпечно)

- [x] **Магазин застосунків**: оцінки користувачів і дозволи кожного застосунку перед встановленням (магазин із Flathub і репозиторіями Arch уже є)
- [x] **Встановлення перетягуванням**, як на Mac: двічі клацніть .exe, .deb, .rpm або AppImage і перетягніть у **Застосунки**
- [x] **Усе стороннє працює в ізольованій коробці**: програми Windows (Bottles), пакунки .deb/.rpm (Podman) та AppImage не бачать вашої системи й файлів без дозволу
- [x] Сторінка **Коробки** в Налаштуваннях: переглядайте, надавайте або забирайте доступ до файлів, мережі, камери й мікрофона та видаляйте коробку
- [x] **Застосунки Android** (APK) у коробці, через Waydroid, які з’являються в меню запуску, як будь-який інший застосунок
- [x] **Ігри в один клік**: Steam, Proton та ігровий режим, з попередженням про ігри, чий античит не працює в Linux
- [x] **Нативні ігри**: Zelda: Majora’s Mask (Zelda64Recomp / 2 Ship 2 Harkinian), Super Mario 64 (Ghostship), Star Fox 64 (Starship), Banjo-Kazooie (Banjo: Recompiled). Встановлення з Магазину → Нативні ігри. Під час першого запуску вкажіть ROM власного картриджа; пакети не містять даних ігор.
- [x] **Ask about the screen** (Meta + S): circle an area to explain, translate or summarize it, with the AI on your computer
- [x] **App actions** (Lingmo Intents): apps offer actions to the Assistant, Flows and Spotlight
- [x] **Assistant with flows, agents and voice** (Meta + Shift + I)
- [x] **One keyboard and mouse for several computers** (Deskflow), with a shared clipboard
