## 路线图

这里是我们接下来要做的事情。已经完成的内容请查看[功能](#recursos)。
日期仅为预估，可能会有变动。建议和优先级在我们的
Discord 上讨论，每一项都会成为 GitHub 上公开的 pull request。

优先级来自论坛和其他发行版评测中最常被提到的问题：
担心更新会搞坏系统、驱动问题、不用终端就能安装软件，
以及无需专业知识也能维护电脑。

### 28/09 至 08/11 · 轻松（且安全地）装软件

- [x] **应用商店**：安装前查看用户评分和每个应用的权限（集成 Flathub 和 Arch 软件仓库的商店已经上线）
- [x] 像 Mac 一样**拖动安装**：双击 .exe、.deb、.rpm 或 AppImage，然后拖到**应用程序**
- [x] **所有外来软件都在隔离环境中运行**：Windows 程序（Bottles）、.deb/.rpm 软件包（Podman）和 AppImage 未经许可无法访问你的系统和文件
- [x] 设置中的**隔离环境**页面：查看、授予或撤销对文件、网络、摄像头和麦克风的访问，并可删除隔离环境
- [x] 在隔离环境中通过 Waydroid 运行 **Android 应用**（APK），像其他应用一样出现在启动器中
- [x] **一键畅玩游戏**：Steam、Proton 和游戏模式，并提醒哪些带反作弊的游戏无法在 Linux 上运行
- [x] **原生游戏**: Zelda: Majora’s Mask (Zelda64Recomp / 2 Ship 2 Harkinian), Super Mario 64 (Ghostship), Star Fox 64 (Starship), Banjo-Kazooie (Banjo: Recompiled). 从商店 → 原生游戏安装。首次启动时，请提供从自己的卡带提取的 ROM；软件包不包含游戏数据。
- [x] **询问屏幕内容**（Meta + S）：圈出一块区域，用电脑上的 AI 解释、翻译或总结
- [x] **应用操作**（Lingmo Intents）：应用向助手、工作流和 Spotlight 提供操作
- [x] **助手支持工作流、智能体和语音**（Meta + Shift + I）
- [x] **一套键盘鼠标控制多台电脑**（Deskflow），并共享剪贴板

- [ ] **发布其余的原生游戏**：Zelda: Ocarina of Time (Ship of Harkinian) 和 Mario Kart 64 (SpaghettiKart)，目前在商店中显示为“即将推出”，一旦项目许可允许分发即会上线
- [ ] 将设置、邮件和文件管理器的侧边栏全部迁移到 **LingmoUI**，与其他应用外观一致
- [ ] 为 **Wayland 会话**铺路：在 Wayland 上测试 Lingmo 的应用和特效（完整会话仍计划于 2027 年推出）

### 09/11 至 13/12 · 电脑维护

- [ ] **系统监视器** (Ctrl + Shift + Esc)：在优化器已显示的处理器、内存和磁盘之外，增加网络和显卡

- [ ] 摄像头背景虚化和替换，抠图精细（头发、耳机和肩膀）

### 14/12 至 31/01/2027 · 放心更新

- [ ] 每次更新前**自动创建还原点** (btrfs)，可直接从启动菜单回滚
- [ ] 在设置和更新程序中提供**“回到昨天”**按钮
- [ ] 更新程序用通俗易懂的语言显示 Arch 新闻，并暂缓需要手动处理的更新
- [ ] **驱动管理器**：检测显卡 (NVIDIA、AMD、Intel) 并安装合适的驱动，随内核保持更新

### 01/02 至 31/03/2027 · 日常硬件

- [ ] **打印机和扫描仪**自动识别，添加界面简单明了
