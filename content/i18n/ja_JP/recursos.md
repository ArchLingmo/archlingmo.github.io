## 機能

以下はすべて、今の ArchLingmo にすでに入っています。

### デスクトップ

- 時計、日付クリックで開くカレンダー、トレイアイコンを備えた **トップバー**
- **コントロールセンター**：Wi-Fi、Bluetooth、ダークモード、夜間モード、おやすみモード、音量をひとつのパネルに
- マウスを重ねるとウィンドウのプレビューが表示され、背景を **単色、ガラス、なし** から選べる **Dock**
- **Spotlight**（Super + Space）：アプリ、ファイル、計算、単位・通貨の換算、ドキュメント内の検索
- **クリップボード履歴**（Super + V）
- **ホットコーナー**：マウスを画面の角に移動すると、すべてのウィンドウの表示、デスクトップの表示、画面のロックができます
- **エフェクト**：ゆらゆら揺れるウィンドウ、魔法のランプ、本のページをめくるような Alt+Tab
- GTK アプリにもグローバルメニュー
- デスクトップに **時計と天気のウィジェット**。選んだ都市の実際の天気予報を表示し、トップバーではひとつのアイコンにまとめて表示

### 人工知能（あなたのパソコンの中で）

- **アシスタント**（Super + I）：Ollama を使い、あなたのパソコン上で動く AI。ドキュメント（PDF、DOCX…）、メモ、カレンダーを読み、システム情報を確認し、隔離されたボックスの中で読み取り専用のターミナルコマンドを実行します。許可があれば、メモ、予定、タスク、ファイルを作成します。変更のたびに確認を求め、何かを削除することは決してありません
- **Spotlight の AI**：「ai:」で始めるとチャット、「?」で終わる質問を入力すれば AI に聞くこともできます。回答ごとにかかった時間と速度を表示し、アシスタントと同じツールを使います
- **設定 › 人工知能**：Ollama の状態、インストール済みのモデル、*このパソコン* へのおすすめ、進行状況付きのモデルのダウンロード、「回答する前に考える」オプション、アシスタントの権限とツール
- **オートメーター**：決まった時刻に実行する毎日のルーティン。コマンドを実行し、必要ならローカル AI が結果を説明します

### 設定

- 初回ログイン時の **ようこそ画面**：ライト／ダークテーマ、アクセントカラー、壁紙、エフェクト
- **ディスプレイ**：ドラッグで配置、回転、メインディスプレイの選択
- 自動スケジュール付きの **夜間モード**、トップバーからキーボード配列の切り替え
- システムと一緒に起動するものを選べる **ショートカット** と **自動起動** のページ
- **ターミナル不要のアップデート**：トップバーに通知が表示され、「アップデート」ボタンで更新
- **48の言語**に対応

### カメラとセキュリティ

- どのアプリでも（Meet、Zoom、Teams、Discord）会議中にカメラを **自動フレーミング**
- ログイン、ロック解除、管理者パスワードの認証に使える **指紋リーダー**
- Web カメラによる **顔認証** でログインとロック解除（失敗したときはパスワードを入力）

### アプリケーション

- **メール**：IMAP と POP3 のアカウントに対応し、プロバイダーを自動検出して、それぞれの設定ガイドを表示（Gmail、Yahoo、iCloud 用のアプリパスワード）。未読数付きのフォルダー、検索とフィルター、スター、アーカイブ、複数メッセージの一括移動・削除、自動ルール、自動補完付きの連絡先、新着メールの通知
- メールの **カレンダーとタスク**：月・週・日・予定リスト表示、繰り返しの予定、アプリを閉じていても届くリマインダー、CalDAV 同期（iCloud、Yahoo、Fastmail、Nextcloud）。今日・今後・期限切れのタスク、「承諾」「仮承諾」「辞退」で返答できる会議の招待（.ics）
- Notion 風の **メモ**：ブロックエディター、「/」メニュー、サブページ、アイコン、お気に入り、ゴミ箱、クイック検索（Ctrl + K）
- **オプティマイザー**：CPU、メモリー、ストレージをクリックすると詳細を表示。ディスク容量が何に使われているかをフォルダーごとに提案付きで示し、メモリーとプロセッサーを最も使っているアプリも表示します。「最適化とクリーンアップ」ボタンで、キャッシュ、アップデートのキャッシュ、古いログ、未使用の Flatpak ランタイムを削除
- ドラッグ＆ドロップと Thunar のような並べ替えに対応した **ファイル** マネージャー
- ダークモードで Dracula テーマ、新しい設定画面でシェル（bash、zsh、fish…）を選べる **ターミナル**、**テキストエディター**、**電卓**、**動画プレーヤー**
- **時計とアラーム**、ISO を USB メモリーに書き込む **USB メディアクリエーター**、**Windows プログラム**（.exe を開くと Linux 版やストアの代替アプリを表示、または Bottles/Wine で試せる）、そして Flathub と Arch のリポジトリをひとつにまとめた **アプリストア**
- すべてのアプリが、ライトテーマでもダークテーマでも同じ Lingmo の見た目
- マイクとシステム音声付きの **スクリーンショットと画面録画**
- **Calamares** インストーラーと **PipeWire** によるサウンド
- **ネイティブゲーム**: Zelda: Majora’s Mask (Zelda64Recomp / 2 Ship 2 Harkinian), Super Mario 64 (Ghostship), Star Fox 64 (Starship), Banjo-Kazooie (Banjo: Recompiled). ストア → ネイティブゲーム からインストールできます。初回起動時に自分のカートリッジから吸い出したROMを指定してください。パッケージにゲームデータは含まれません。
