## ロードマップ

これから作っていくもの。すでに完成しているものは[機能](#recursos)をご覧ください。
日程は予定であり、変更される場合があります。提案や優先順位は私たちの
Discord で話し合われ、各項目は GitHub 上の公開 pull request になります。

優先順位は、フォーラムや他のディストリビューションのレビューで特によく挙がる声をもとに決めています。
アップデートでシステムが壊れる不安、ドライバー、ターミナルを使わないソフトのインストール、
そして専門知識なしでパソコンを手入れできることです。

### 28/09〜08/11 · 手間いらずのアプリ（そして安全に）

- [x] **アプリストア**: ユーザーの評価と、インストール前に各アプリの権限を表示（Flathub と Arch のリポジトリをまとめたストアはすでに利用可能）
- [x] Mac のように**ドラッグでインストール**: .exe、.deb、.rpm、AppImage をダブルクリックして**アプリケーション**へドラッグ
- [x] **外部のものはすべて隔離されたボックスで実行**: Windows プログラム (Bottles)、.deb/.rpm パッケージ (Podman)、AppImage は、許可なしにシステムやファイルを見ることができません
- [x] 設定の**ボックス**ページ: ファイル、ネットワーク、カメラ、マイクへのアクセスを確認・許可・取り消し、ボックスの削除も
- [x] Waydroid によるボックス内の **Android アプリ** (APK)。ほかのアプリと同じようにランチャーに表示
- [x] **ワンクリックでゲーム**: Steam、Proton、ゲームモード。Linux で動作しないアンチチート搭載ゲームには警告を表示
- [x] **ネイティブゲーム**: Zelda: Majora’s Mask (Zelda64Recomp / 2 Ship 2 Harkinian), Super Mario 64 (Ghostship), Star Fox 64 (Starship), Banjo-Kazooie (Banjo: Recompiled). ストア → ネイティブゲーム からインストールできます。初回起動時に自分のカートリッジから吸い出したROMを指定してください。パッケージにゲームデータは含まれません。
- [x] **画面について質問**（Meta + S）：範囲を囲んで、パソコン上の AI で説明、翻訳、要約
- [x] **アプリのアクション**（Lingmo Intents）：アプリがアシスタント、フロー、Spotlight にアクションを提供
- [x] **フロー、エージェント、音声に対応したアシスタント**（Meta + Shift + I）
- [x] **1 組のキーボードとマウスで複数のパソコンを操作**（Deskflow）。クリップボードも共有
