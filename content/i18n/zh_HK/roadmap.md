## 路線圖

以下是我們接下來會打造的內容。已經完成的部分請參閱[功能](#recursos)。
日期只屬預計，或會有所更改。建議和優先次序會在我們的
Discord 上討論，每個項目都會成為 GitHub 上公開的 pull request。

優先次序來自論壇和其他發行版評測中最常提及的問題：
擔心更新會令系統出問題、驅動程式、毋須終端機就能安裝程式，以及
不用懂技術也能打理好電腦。

### 28/09 – 08/11 · 輕鬆（又安全地）用程式

- [ ] **應用程式商店**：安裝前查看用戶評分及每個應用程式的權限（集合 Flathub 和 Arch 軟件庫的商店已經推出）
- [ ] 像 Mac 一樣**拖曳安裝**：按兩下 .exe、.deb、.rpm 或 AppImage，再拖到「**應用程式**」
- [ ] **所有外來程式都在隔離箱內執行**：Windows 程式（Bottles）、.deb/.rpm 套件（Distrobox）及 AppImage 未經許可都無法看到你的系統或檔案
- [ ] 「設定」內的**隔離箱**頁面：查看、授予或移除對檔案、網絡、相機及咪高峰的存取權，並可刪除隔離箱
- [ ] 透過 Waydroid 在隔離箱內執行 **Android 應用程式**（APK），像其他程式一樣出現在啟動器中
- [ ] **一按即玩遊戲**：Steam、Proton 和遊戲模式，並就反作弊系統無法在 Linux 上運作的遊戲發出警告
- [x] **原生遊戲**: Zelda: Majora’s Mask (Zelda64Recomp / 2 Ship 2 Harkinian), Super Mario 64 (Ghostship), Star Fox 64 (Starship), Banjo-Kazooie (Banjo: Recompiled). 從商店 → 原生遊戲安裝。首次啟動時，請提供從自己的卡帶擷取的 ROM；套件不包含遊戲資料。
- [ ] **更多原生遊戲**：Zelda: Ocarina of Time (Ship of Harkinian) 及 Mario Kart 64 (SpaghettiKart)，在商店中仍顯示「即將推出」

### 09/11 – 13/12 · 打理你的電腦

- [ ] **系統監察器**（Ctrl + Shift + Esc）：在優化工具已顯示的處理器、記憶體和磁碟以外，再加上網絡和顯示卡
- [ ] **系統資料**，附「複製報告」按鈕，方便在 Discord 或論壇上求助
- [ ] 相機背景模糊和替換，並提供高質素去背（頭髮、耳機和肩膊）

### 14/12 – 31/01/2027 · 放心更新

- [ ] 每次更新前自動建立**還原點**（btrfs），並可直接從開機選單還原
- [ ] 在設定和更新程式中提供「**返回昨天**」按鈕
- [ ] 更新程式以淺白易明的語言顯示 Arch 新聞，並暫緩需要手動處理的更新
- [ ] **驅動程式管理員**：偵測顯示卡（NVIDIA、AMD、Intel）並安裝合適的驅動程式，隨核心保持更新

### 01/02 – 31/03/2027 · 日常硬件

- [ ] **打印機和掃描器**自動識別，並提供簡單的新增畫面
- [ ] **藍牙耳機**：可在音樂質素和咪高峰之間選擇，通話完結後自動回復高質素
- [ ] **電池**：充電上限 80% 以延長壽命、電源設定檔和電池健康狀況
- [ ] 所有應用程式都有清晰的分數縮放（125%、150%），可按螢幕分別設定

### 01/04 – 31/05/2027 · 整合與外觀

- [ ] 一按**切換版面**：macOS 風格、Windows 風格或 Lingmo
- [ ] 在檔案管理員中查看檔案的**舊版本**，就像 Time Machine
- [ ] **手機整合**：與 Android 和 iPhone 同步通知、檔案和剪貼簿（KDE Connect）
- [ ] **雲端帳戶**：Google Drive 和 OneDrive 直接顯示在檔案管理員中
- [ ] 從螢幕截圖中複製文字（OCR）
- [ ] 安裝程式在與 Windows 並存安裝時，會提醒 BitLocker 和 Secure Boot 相關事項

### 2027 年 6 月起

- [ ] AI 助理：在任何應用程式中摘要、翻譯和解釋所選文字
- [ ] 家長監控：螢幕使用時間和睡覺時間
- [ ] Wayland 工作階段
- [ ] 每個版本的 ISO 都會自動建置和測試
- [ ] 為有需要的人提供整合 Windows 的 Office 和 Adobe（WinBoat）
